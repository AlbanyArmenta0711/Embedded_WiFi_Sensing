# The ESP32 CSI Web Collecting Tool with ESP32

In this repository you will find a **tool for collecting Wi-Fi** using ESP32 devices; a **human activity recognition dataset**, collected using the proposed CSI tool; and **Deep Learning models** trained using the dataset, which are ready to be deployed in the ESP32 (External RAM in these devices is highly recommended). We encourage to send emails at the email presented at the end of this README for comments/doubts or create an Issue in this repository.
